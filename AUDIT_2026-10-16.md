## E. Security

Verified: Helmet headers; JSON body limits; rate limits (tests); auth on every protected route (tests incl. sign-in-required lists); RLS owner-only reads and no client writes on all user tables (DB tests + `verify_production.sql`); account deletion cascades; Points ledger append-only and never negative (DB trigger); Play purchases verified server-side with Google, bound to the account, acknowledged only when entitled; RTDN requires Google's signed push token; no service-role key, private key or Gemini key in any client bundle (scanned); release manifest: `allowBackup=false`, cleartext off, SMS receiver protected by `BROADCAST_SMS`, receivers not exported.

Unresolved risks: SMS permissions (`READ_SMS`, `RECEIVE_SMS`) need the Play Console SMS declaration to be accepted — status not verifiable from here; no penetration test; static scans finding nothing is not proof of security.
